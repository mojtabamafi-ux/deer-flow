# راهنمای اجرا و استفاده

این راهنما فقط دستورهایی را دارد که واقعاً اجرا و خروجی‌شان بررسی شده است.

## ۱) نصب

هسته تحلیل **فقط کتابخانه استاندارد پایتون** است؛ برای CLI هیچ نصبی لازم نیست.
داشبورد به سه پکیج نیاز دارد:

```bash
cd deer-flow
python3 -m venv .venv
.venv/bin/pip install fastapi uvicorn plotly          # داشبورد
.venv/bin/pip install pytest httpx jdatetime ruff pyyaml   # اختیاری: تست، لینتر و اعتبارسنج
```

نسخه‌های بررسی‌شده: `fastapi 0.141.1`، `uvicorn 0.52.4`، `plotly 7.0.0`، پایتون ۳.۱۱.
از این به بعد در دستورها `python` یعنی `.venv/bin/python`.

نکته: پوشه `.venv` در `.gitignore` است و بین نشست‌ها پاک می‌شود؛ اگر خطای
`No such file or directory` برای مفسر پایتون دیدید، یعنی باید مرحله ۱ را تکرار کنید.

## ۲) اجرای داشبورد

```bash
cd deer-flow/skills/public/iran-market-analysis/scripts
python serve_dashboard.py --host 0.0.0.0 --port 8010 --mode sample
```

سپس `http://localhost:8010` را باز کنید. گزینه‌ها:

| گزینه | پیش‌فرض | توضیح |
| --- | --- | --- |
| `--host` | `0.0.0.0` | روی همه اینترفیس‌ها؛ برای دسترسی از پروکسی/کانتینر لازم است |
| `--port` | `8010` | پورت |
| `--mode` | `auto` | `auto` = تلاش برای داده زنده و در صورت شکست داده نمونه؛ `live` = فقط زنده (خطا می‌دهد)؛ `sample` = فقط داده مصنوعی، بدون شبکه |
| `--reload` | خاموش | بارگذاری مجدد خودکار، فقط برای توسعه |

خروجی شروع:


### اجزای صفحه

- **نوار ابزار**: بازار → نماد (با جست‌وجو) → تایم‌فریم → تعداد کندل (۲۰۰/۴۰۰/۸۰۰) → «تحلیل دوباره».
- **نمودار قیمت**: کندل‌استیک + ۴ subplot (حجم، RSI، MACD). چیپس‌های لایه‌ها:
  `EMA20`، `EMA50`، `EMA200`، `بولینگر`، `سوپرتند`، `SAR`، `ایچیموکو`، `الیوت`،
  `نواحی RTM`، `OB/FVG`، `رنج ACT`، `سیگنال‌ها`.
- **بنر منبع داده**: اگر `sample` باشد، هشدار می‌دهد که قیمت‌ها مصنوعی‌اند.
- **کارت پیشنهاد** (جدا و برجسته): اقدام، امتیاز هم‌راستایی، ورود/استاپ/هدف ۱/هدف ۲، R:R،
  دلایل، ریسک‌ها و «پشتیبان سیگنال‌ها: عوامل هم‌راستا».
- **پنل‌ها**: سیگنال‌های معاملاتی (با فیلتر موتور: همه/RTM/ACT/ICT/الیوت/ستاپ‌ها)،
  شمارش امواج الیوت، الگوهای شناسایی‌شده، اهداف و سطح بی‌اعتباری، نواحی عرضه و تقاضا (RTM)،
  ICT و ساختار بازار، فاز ACT، ستاپ‌ها و نرخ پیروزی اندازه‌گیری‌شده، اندیکاتورهای فعال.
- **«بررسی اتصال منابع»**: تنها دکمه‌ای که شبکه را پروب می‌کند (`/api/sources?force=true`).
  خودِ صفحه هرگز پروب نمی‌کند، چون پروب سرد ۳ منبع ممکن است دقیقه‌ها طول بکشد.

## ۳) CLI تحلیل

```bash
# فهرست نمادها
python analyze.py --list

# گزارش خوانا
python analyze.py --symbol فولاد --timeframe D1 --bars 400

# خروجی کامل JSON (برای پردازش برنامه‌ای)
python analyze.py --code 46348559193224090 --json > analysis.json

# اسکن یک بازار
python analyze.py --scan equity --timeframe D1

# تحلیل فایل CSV خودتان
python analyze.py --file history.csv --symbol MYDATA

# حالت کاملاً آفلاین
python analyze.py --symbol BTC_USDT --mode sample
```

| گزینه | توضیح |
| --- | --- |
| `--symbol` / `--code` | نام فارسی نماد یا کد (insCode). این دو با هم و با `--scan`/`--list` ناسازگارند |
| `--file` | تاریخچه CSV/JSON محلی؛ همراه `--symbol` نام سری را مشخص می‌کند |
| `--timeframe, -t` | `M5 M15 M30 H1 H4 D1 W1 MN1` (پیش‌فرض `D1`) |
| `--bars` | پنجره نمودار (پیش‌فرض ۴۰۰) |
| `--backtest-bars` | تاریخچه‌ای که نرخ پیروزی روی آن اندازه‌گیری می‌شود (پیش‌فرض ۱۲۰۰) |
| `--no-backtest` | بدون بک‌تست (سریع‌تر) |
| `--mode` | `auto` / `live` / `sample` |
| `--allow-short` | اجازه ستاپ فروش؛ فقط برای آتی/کالا/ارز/رمزارز. در سهام بورس به‌طور پیش‌فرض خاموش است |
| `--json` | خروجی ماشین‌خوان |

کد خروج: `0` موفق، `2` آرگومان نامعتبر، `3` داده‌ای تولید نشد.

## ۴) خواندن خروجی

نمونه واقعی (`--symbol فولاد --mode sample --bars 200 --backtest-bars 800`):

```
فولاد مبارکه اصفهان (46348559193224090) - equity
منبع داده: sample | تایم‌فریم: D1 | کندل‌ها: 200 از 800
هشدار: داده‌ها مصنوعی (sample) هستند و قیمت واقعی بازار نیستند.
قیمت: 1,519.00  تغییر: -0.78%  روند: خنثی / رنج  ADX: 14.4
امواج الیوت: یک ساختار پنج‌موجی نزولی شناسایی شد: 1 (1,637) → 2 (1,897) → 3 (1,380)
             → 4 (1,584) → 5 (1,399). اعتبار شمارش: 61/۱۰۰. سطح بی‌اعتباری: 1,897.
RTM: 58 ناحیه، 14 فعال، 44 شکسته‌شده
ACT: بدون فاز
پیشنهاد: بازار در وضعیت خنثی است - صبر برای ستاپ بهتر  (امتیاز -8.3, اطمینان 0.083)
کل: 86 معامله | پیروزی 41.9% | امید 0.2105R | ضریب سود 1.368 | افت 10.9846R
```

ترتیب خواندن:

1. **منبع داده** — اگر `sample` است، هیچ عدد قیمتی را به بازار نسبت ندهید.
2. **روند و ADX** — ADX زیر ۲۰ یعنی بازار رنج؛ اکثر ستاپ‌های روندی در این حالت کار نمی‌کنند.
3. **شمارش الیوت** — «اعتبار شمارش» از ۱۰۰ و «سطح بی‌اعتباری» سطحی است که اگر قیمت از آن
   عبور کند، شمارش باطل است.
4. **RTM** — نسبت «فعال» به «شکسته‌شده» نشان می‌دهد چند ناحیه هنوز معتبر است.
5. **ستاپ‌ها** — فقط سطرهایی با **۲۰ معامله یا بیشتر** قابل استنادند؛ بقیه `نمونه کم` می‌گیرند.
   در مثال بالا فقط `RTM - ناحیه تقاضای DBR` با ۲۵ معامله درجه C گرفته است.
6. **پیشنهاد** — امتیاز بین ۱۰۰− تا ۱۰۰+؛ آستانه خرید ۳۵+ و فروش ۳۵−. اگر سیگنال ورود
   معتبر وجود نداشته باشد، حتی با امتیاز بالا اقدام `wait` می‌ماند.
7. **ریسک‌ها** — شامل هشدار CHoCH، فشردگی نوسان، ورود دور از قیمت، و سیگنال‌های فروشی که
   به دلیل نبود فروش استقراضی حذف شده‌اند.

### معنی معیارها

| معیار | تعریف |
| --- | --- |
| `نرخ پیروزی` | سهم معاملات با R مثبت، روی همان داده‌ای که تحلیل شده |
| `امید (R)` | میانگین سود بر حسب ریسک هر معامله؛ عدد کلیدی برای مقایسه ستاپ‌ها |
| `ضریب سود (PF)` | مجموع سود ناخالص تقسیم بر مجموع زیان ناخالص |
| `افت (R)` | بیشترین افت انباشته منحنی سرمایه بر حسب R |
| `درجه A/B/C/D` | A: پیروزی ≥۷۰٪ و امید ≥۰.۴ — B: ≥۶۰٪ و ≥۰.۲ — C: ≥۵۰٪ و ≥۰ — زیر ۲۰ معامله: `نمونه کم` |

فرض‌های بدبینانه بک‌تست: ثبت معامله در باز شدن کندل **بعد** از سیگنال، سفارش محدود فقط اگر
قیمت واقعاً از آن عبور کند، برخورد هم‌زمان استاپ و هدف در یک کندل = **استاپ**، کارمزد ۶bps +
اسلیپیج ۵bps در هر طرف، و حذف استاپ‌های تنگ‌تر از ۰.۲۵٪ قیمت.

## ۵) بررسی اتصال و داده زنده

```bash
python doctor.py                     # پروب همه اندپوینت‌ها
python doctor.py --json              # خروجی ماشین‌خوان
python doctor.py --discover --write  # پرکردن جدول نمادها از TSETMC_AllSymbols
python doctor.py --verify-symbols --write   # راستی‌آزمایی/اصلاح کدهای موجود
```

در محیطی بدون دسترسی، خروجی واقعی این است:

```
حالت پیکربندی‌شده: auto  |  حالت مؤثر: sample
دسترسی زنده به حداقل یک منبع: خیر
  [ERR] TSETMC_AllSymbols   https://old.tsetmc.com/tsev2/data/InstSimple/IsPlus/-1
        URL error: TLS/SSL connection has been closed (EOF)
  [ERR] Market_CGCC_Gold    https://www.market.cgcc.ir/api/v1/gold
        URL error: [Errno -2] Name or service not known
```

تا وقتی `doctor.py` روی شبکه شما `OK` نشان نداده، هیچ اندپوینتی تأییدشده نیست
(همه با `verified: false` منتشر شده‌اند) و اعداد را باید `sample` فرض کنید.
بدون `--write` هیچ فایلی تغییر نمی‌کند؛ `--write` بدون `--discover` یا
`--verify-symbols` با کد خروج ۲ رد می‌شود.
